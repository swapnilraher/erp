How to prepare GSTR-1 in Techstar ERP

Techstar ERP prepares GSTR-1 for you from the invoices in your books: B2B and B2C figures, credit notes, the invoice numbers used (table 13) and checks. You download the JSON, file the return yourself on the GST portal and then record the ARN in the ERP.

⏱ About 5 minutes Menu: GST → GSTR-1 Filed by you on the GST portal

Before you start

ℹ️

The ERP prepares, you file. GSTR-1 is worked out from your sales invoices, credit notes and receipts. This software does not connect to the GSTN and does not file returns: you file GSTR-1 on the GST portal and record its ARN here.

Your GSTIN is saved in Settings → Business details & GST (and on each branch). A return is made per GSTIN.

All the month's invoices are entered — see How to make a sales invoice.

Open GSTR-1 and pick the month

In the left menu click GST → GSTR-1 A. The screen opens on the month whose return is due now.

  • Return period B — the month of the return (the example uses October 2026).
  • Financial year and GSTIN — if your branches have different GSTINs, pick the one you are filing for.

The box on the right C shows the due dates of the month and the days left. Below, GST return frequency says whether GSTR-3B is filed monthly or quarterly (QRMP); the due dates follow it.

Check the figures

The tiles A sum up the return:

TileWhat it counts
B2B invoicesSales to GST-registered buyers (with a GSTIN): number of invoices and taxable value.
B2C largeAn invoice over ₹1 lakh to an unregistered buyer in another State.
B2C smallAll other sales to unregistered buyers (retail), reported by rate and State.
Credit / debit notesNotes issued in the month.
ChecksErrors and warnings found in the return — green when there are none.

Books vs return B compares the Output GST ledgers of the month with the tax in the return. If a bill's entry in the books carries different GST, it is listed here. Table 13 C lists the invoice numbers used in the month by series; a missing number is reported as cancelled and shown in yellow.

💡

When the return has errors or warnings, a Checks of the return table lists each one with its section, the document and what to correct. Correct the invoice in Sales and open GSTR-1 again — it is prepared fresh every time. See also Pre-filing checks.

Download the JSON

Click Download JSON for the GST Offline Tool (gst.gov.in) A. The file is named like GSTR1_<GSTIN>_2026-10.json and holds the whole return as worked out from your books.

File GSTR-1 on the GST portal

Use the JSON with the GST Offline Tool from gst.gov.in, check the figures there and file GSTR-1 on the GST portal with your own login. The portal gives you an ARN (acknowledgement reference number) when the return is filed.

⚠️

Nothing is sent to the GST portal from Techstar ERP. Filing, and the OTP / signature it needs, always happens on the portal.

Record the ARN

Back in the ERP, under Filed on the GST portal? Record the ARN, type the 15-character ARN B exactly as on the portal's acknowledgement and the Filed on date. Then click Mark filed C.

The ERP keeps the return as it was at that moment with the ARN, and the month is locked for sales documents, so a filed month cannot change by mistake.

If the return's checks still show errors, the ERP asks Mark it filed anyway? — confirm only if the return on the portal was filed as it is.

See the filed returns

The Filed returns tab A lists every return you recorded: return, period, GSTIN, ARN B and filing date.

Common questions

Does Techstar ERP file GSTR-1 for me?
No. The ERP prepares the return and the JSON from your books. You file it on the GST portal yourself and then record the ARN in the ERP.
I found a mistake after filing GSTR-1. What now?
Correct an invoice already reported with GST → More GST → GSTR-1A amendments — see GSTR-1A amendments — or issue a credit note, as the case needs.
Why is the Download JSON button grey?
The JSON is made only for a valid filing GSTIN. Add or correct the GSTIN in Settings → Business details & GST (or on the branch); the error shows in the checks.
I have two GSTINs. How do I prepare both?
Pick each GSTIN in the GSTIN box in turn. Each one gets its own GSTR-1, JSON and ARN.
Why does table 13 show a number as cancelled?
Every number between the first and the last invoice of a series must be accounted for. A number that was never issued is reported as cancelled and a warning asks you to keep the reason on record.
