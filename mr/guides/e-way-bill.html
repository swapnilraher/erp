ई-वे बिल कसे बनवायचे

ई-वे बिल कधी लागते?

मालाची किंमत मर्यादेपेक्षा जास्त असेल तर माल हलवण्याआधी ई-वे बिल लागते — एका राज्यातून दुसऱ्या राज्यात माल जाताना ही मर्यादा ₹50,000 आहे. राज्याच्या आत मर्यादा राज्यानुसार वेगळी असते (उदा. महाराष्ट्रात ₹1,00,000).

हे लक्षात ठेवायची गरज नाही: e-Way Bills यादीत ई-वे बिल लागत असेल तर इनव्हॉइसवर Pending दिसते, नाहीतर त्या विक्रीच्या राज्यांनुसार लागू मर्यादेसह Not required (up to ₹…) दिसते.

एकदाच करायचा सेटअप: ई-वे बिल पोर्टल लॉगिन

  1. ewaybillgst.gov.in वर तुमच्या GSTIN साठी API user बनवा (Registration → For GSP, तुमचा GSP निवडून).
  2. Techstar ERP मध्ये GST → E-Invoice / E-Way Bill → GST Configuration A उघडा (मराठी menu मध्ये: GST → ई-इनव्हॉइस / ई-वे बिल).
  3. डावीकडे तुमचा GSTIN निवडा, e-Way Bill API user चे नाव आणि पासवर्ड B टाका आणि save करा. Save करताना लॉगिन पोर्टलवर तपासले जाते, आणि पासवर्ड encrypt करून ठेवले जातात.
ℹ️

अजून API user नाही? तरीही ERP वापरू शकता: तोच फॉर्म भरा आणि Download JSON वर click करा. ती फाइल ई-वे बिल पोर्टलवर upload करा, बिल तिथे बनते. (या software मधून GST रिटर्न भरले जात नाहीत.)

e-Way Bills टॅब उघडा

GST → E-Invoice / E-Way Bill वर जा आणि e-Way Bills टॅब A उघडा. प्रत्येक सेल्स इनव्हॉइस त्याचा ग्राहक, तारीख, किंमत आणि ई-वे बिलाच्या स्थितीसह दिसते. इनव्हॉइस शोधण्यासाठी All / Active / Pending / Cancelled टॅब किंवा शोध बॉक्स वापरा.

इनव्हॉइस निवडा

इनव्हॉइसच्या ओळीवरील Generate B वर click करा, किंवा + New e-Way Bill C वर click करून यादीतून इनव्हॉइस निवडा. योग्य इनव्हॉइस निवडले आहे हे तपासण्यासाठी इनव्हॉइसचा ग्राहक, GSTIN आणि किंमत दिसते.

वाहतुकीची माहिती (Part B) भरा

Generate करा

डिलिव्हरीचे City / place A आणि PIN code B तपासा, मग Generate e-Way Bill C वर click करा. ERP इनव्हॉइस आणि वाहतुकीची माहिती ई-वे बिल पोर्टलला पाठवतो आणि ई-वे बिल नंबर व त्याची वैधता इनव्हॉइसवर नोंदवतो. Download JSON D त्याऐवजी पोर्टलवर upload करण्याची फाइल बनवते.

ई-वे बिल Active झाले

इनव्हॉइसवर आता Active, 12 अंकी ई-वे बिल नंबर आणि Valid up to (कधीपर्यंत वैध) दिसते. वैधता पोर्टल अंतरावरून ठरवते — साधारण मालासाठी प्रत्येक 200 km साठी सुमारे एक दिवस.

प्रिंट, गाडी बदलणे, मुदतवाढ किंवा रद्द करणे

ओळीवरील ⋯ बटणावर click करा:

  • Print e-Way Bill — प्रिंट ड्रायव्हरला द्या; View on portal पोर्टलवरची नोंद दाखवते.
  • Update vehicle (Part B) — माल दुसऱ्या गाडीत गेला (गाडी बिघडली, माल दुसऱ्या गाडीत चढवला); कारण निवडा.
  • Change transporter — बिल दुसऱ्या transporter कडे द्या.
  • Extend validity — बिलाची मुदत संपण्याच्या 8 तास आधीपासून 8 तास नंतरपर्यंत दिसते, माल वेळेत पोहोचू शकत नसेल तेव्हा.
  • Cancel e-Way Bill — बनवल्यापासून 24 तासांच्या आत आणि वाटेत मालाची तपासणी होण्यापूर्वीच. रद्द केलेले बिल पुन्हा वापरता येत नाही; नवीन बनवा.

ई-वे बिल बनवण्याचे इतर मार्ग

  • इनव्हॉइस save केल्यावर लगेच — माल मर्यादेपेक्षा जास्त असेल तर save झालेल्या इनव्हॉइसवर Generate E-Way Bill लिंकसह पिवळी सूचना दिसते. तुम्ही ई-इनव्हॉइस वापरत असाल तर उघडणाऱ्या विंडोत IRN बनवा; तीच विंडो नंतर वाहतुकीची माहिती विचारून ई-वे बिल बनवते. पहा सेल्स इनव्हॉइस कसे बनवायचे.
  • From challan / return — डिलिव्हरी चलन, sales return आणि purchase return साठी: दस्तऐवजाचा नंबर टाका, माहिती आणा आणि generate करा.
  • Trip sheet (combine bills) — वरच्या ⋯ menu मध्ये: एका गाडीतील अनेक बिलांसाठी एक consolidated ई-वे बिल.
  • Bills where I am the transporter — इतरांनी तुमच्या GSTIN ला (transporter म्हणून) दिलेली ई-वे बिले.

नेहमीचे प्रश्न

यादीत “Not required” दिसते. तरीही ई-वे बिल बनवता येते का?
हो. प्रत्येक इनव्हॉइसवर Generate बटण असते, उदा. मर्यादेखाली असूनही transporter ई-वे बिल मागतो तेव्हा.
लॉगिन किंवा credentials बद्दल error येतो.
GST → E-Invoice / E-Way Bill → GST Configuration मध्ये e-Way Bill API user save करा (वरचा एकदाचा सेटअप पहा). नाव आणि पासवर्ड ई-वे बिल पोर्टलवर बनवल्याप्रमाणे अगदी तसेच असावेत.
गाडी नंबर आवश्यक आहे का?
रस्त्याने पाठवताना गाडी नंबर किंवा transporter ID यापैकी एक लागतो. गाडी अजून ठरली नसेल तर आता transporter ID द्या आणि नंतर Update vehicle (Part B) ने गाडी जोडा.
ई-वे बिलात चूक झाली.
24 तासांच्या आत ते रद्द करा (⋯ → Cancel e-Way Bill, कारणासह) आणि नवीन बनवा. फक्त गाडी बदलली असेल तर रद्द न करता Update vehicle वापरा.
ई-वे बिलामुळे माझा हिशोब बदलतो का?
नाही. ई-वे बिल नंबर आणि वैधता नोंदीसाठी व प्रिंटसाठी इनव्हॉइसवर ठेवली जाते; इनव्हॉइसची रक्कम आणि तुमचा हिशोब जसा आहे तसाच राहतो.
