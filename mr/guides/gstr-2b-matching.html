तुमचे GSTR-2B GST पोर्टलवरून डाउनलोड करा आणि ती फाइल Techstar ERP मध्ये import करा. सुरू करण्यापूर्वी

ℹ️

GSTR-2B फक्त तुम्ही डाउनलोड केलेल्या फाइलमधूनच येते — GST पोर्टलवरून. GST पोर्टलशी थेट जोडणी नाही: आधी डाउनलोड, मग import.

तुमचा हिशोब जसा आहे तसाच राहतो. Import केलेले GSTR-2B फक्त जुळवणीसाठीचा पुरावा आहे. त्यातून कधीच खरेदी बिल किंवा जर्नल बनत नाही, कोणतेही लेजर, GST input ledger किंवा स्टॉक बदलत नाही आणि ITC क्लेम होत नाही. तुमचा हिशोबच खरा आधार राहतो.

महिन्याची खरेदी बिले टाकलेली असावीत — पहा खरेदी बिल कसे टाकायचे.

GSTR-2B matching उघडा

डाव्या menu मध्ये GST → GSTR-2B matching A वर click करा (मराठी menu मध्ये: GST → GSTR-2B जुळवणी). वरच्या कार्डमध्ये B तीन पायऱ्या दिसतात: GST पोर्टलवरून डाउनलोड, डाउनलोड केलेली फाइल import, जुळवणी तपासणे. त्याखालील Accounting Safety Note C पुन्हा सांगते की import मुळे कुठलीही नोंद होत नाही.

GST पोर्टलवरून GSTR-2B डाउनलोड करा

gst.gov.in वर त्या महिन्याचे Returns → GSTR-2B उघडा आणि JSON किंवा Excel फाइल डाउनलोड करा. फाइल डाउनलोड केली तशीच ठेवा; ERP पोर्टलचीच रचना वाचतो.

फाइल import करा

  • Return period A — GSTR-2B चा महिना (स्क्रीनवरचा महिना आपोआप येतो; उदाहरणात ऑक्टोबर 2026).
  • Match strictness B — Exact (number, date and tax), Number and GSTIN (tax may differ) किंवा Loose (number spelled differently). जास्त कडक पर्याय निवडला तर सैल जुळणी फरक म्हणून दिसते.
  • Replace this month's import C — पोर्टलने पुन्हा तयार केलेले GSTR-2B import करताना टिक करा; ते महिन्याचे आधीचे import बदलते आणि तुम्ही नोंदवलेल्या IMS कृती तशाच ठेवते.

GSTR-2B import होईपर्यंत महिन्याचे प्रत्येक खरेदी बिल Missing in GSTR-2B दिसते. Import GSTR-2B file for Oct 2026 (JSON / Excel) D वर click करा आणि फाइल निवडा.

काहीही save होण्याआधी फाइल तपासली जाते: तिचा GSTIN तुमच्याच GSTIN पैकी एक असावा आणि रिटर्न महिना तुम्ही निवडलेलाच असावा. प्रत्येक दस्तऐवज तपासला जातो आणि आधी import झालेले बिल duplicate म्हणून सोडले जाते. मग किती दस्तऐवज import झाले ते संदेशात दिसते; नाकारलेल्या ओळी कारणासह दिसतात.

सारांशात A Bills in GSTR-2B, Matched, Differences or missing आणि Match % दिसते.

निकाल समजून घ्या

Your purchases vs GSTR-2B मध्ये तुमच्या हिशोबातील प्रत्येक बिल GSTR-2B मधील पुरवठादाराच्या दस्तऐवजाशेजारी, जुळणीची पातळी (match level) आणि निकालासह दिसते:

निकालअर्थ आणि काय करायचे
Matched Aपुरवठादाराचा GSTIN, नंबर, तारीख आणि टॅक्स सारखे. काही करायचे नाही.
Mismatch Bबिल सापडले पण taxable value, टॅक्स किंवा तारीख वेगळी. Difference (books − 2B) किती फरक ते दाखवते. तुमचे बिल तपासा; चूक पुरवठादाराची असेल तर त्याला दुरुस्त करायला सांगा.
Missing in Purchase Register CNot in your books: पुरवठादाराने कळवलेले, पण तुम्ही न टाकलेले बिल. तुमचे असेल तर टाका; नसेल तर पुरवठादाराशी बोला.
Missing in GSTR-2B Dतुमच्या हिशोबात आहे, पण पुरवठादाराने कळवले नाही (किंवा GSTIN वेगळा). त्याचे ITC पुढच्या GSTR-2B मध्ये दिसेपर्यंत थांबते.
Ineligible ITCGSTR-2B मध्ये ITC उपलब्ध नाही असे दाखवले आहे, किंवा ओळ blocked म्हणून चिन्हांकित केली.
💡

GSTR-3B हेच GSTR-2B वापरून table 4 मधील ITC मर्यादित करते: GSTR-2B मध्ये नसलेले बिल पुढच्या GSTR-2B मध्ये दिसेपर्यंत पुढे ढकलले जाते. पहा GSTR-3B तयार करा आणि रिटर्नआधी तपासणी.

ITC नोंदी आणि export

स्वतःच्या तपासणीसाठी GSTR-2B ओळीवर Mark blocked u/s 17(5) किंवा Mark for reversal वर टिक करता येते. ERP आधी विचारतो आणि ते काय करते ते सांगतो A: फक्त GSTR-2B ओळीवर एक नोंद जोडली जाते. कोणतीही entry होत नाही, आणि हिशोब, GST input ledger आणि रिटर्नमधील ITC बदलत नाही. Reversal करायचे असेल तर ते GST returns → ITC register मधून स्वतः नोंदवा.

Export Reconciliation (मागच्या screenshot मधील बॉक्स E) यादी Excel, CSV किंवा PDF मध्ये, तुमच्या व्यवसायाच्या नावासह, save करते. Re-run matching पुन्हा जुळवणी करते, उदा. गहाळ बिल टाकल्यानंतर.

नेहमीचे प्रश्न

Techstar ERP GST पोर्टलवरून GSTR-2B आणतो का?
नाही. GSTR-2B साठी GST पोर्टलशी थेट जोडणी नाही. तुम्ही gst.gov.in वरून (Returns → GSTR-2B) फाइल डाउनलोड करता आणि इथे import करता.
GSTR-2B import केल्याने खरेदी बिले बनतील किंवा ITC क्लेम होईल का?
नाही. Import फक्त जुळवणीसाठीचा पुरावा आहे. त्यातून खरेदी किंवा जर्नल बनत नाहीत, लेजर, स्टॉक किंवा GST input ledger बदलत नाही आणि ITC क्लेम होत नाही. न टाकलेली बिले तुम्ही स्वतः टाकेपर्यंत Not in your books म्हणूनच दिसतात.
Import करताना GSTIN किंवा महिना जुळत नाही असे येते.
फाइल तुमच्याच एका GSTIN चे आणि Return period मध्ये निवडलेल्या महिन्याचेच GSTR-2B असावी. योग्य महिना निवडा, किंवा पोर्टलवरून योग्य फाइल डाउनलोड करा.
तीच फाइल दोनदा import केली. बिले दोनदा मोजली जातील का?
नाही. आधी import झालेला दस्तऐवज duplicate म्हणून सोडला जातो. पोर्टलने पुन्हा तयार केलेले GSTR-2B भरायचे असेल तर Replace this month's import वर टिक करा.
पुरवठादाराने नंबर वेगळ्या पद्धतीने लिहिल्यामुळेच बिल "Mismatch" दिसते.
Match strictness मध्ये Loose (number spelled differently) निवडा. मग अशी बिले level 3 वर जुळतात.
