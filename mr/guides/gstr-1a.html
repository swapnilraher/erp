सुरू करण्यापूर्वी

ℹ️

GSTR-1 मध्ये आधी कळवलेल्या इनव्हॉइससाठी. स्क्रीनवर सांगितल्याप्रमाणे, GSTR-1A ने एखाद्या महिन्याचे GSTR-3B भरण्याआधी त्या महिन्याची इनव्हॉइस आणि क्रेडिट नोट दुरुस्त करता येतात.

ERP नोंदवतो, तुम्ही भरता. दुरुस्ती इथे save होते आणि GSTR-1A JSON मध्ये जाते. GST पोर्टलला काहीही पाठवले जात नाही: JSON तुम्ही upload करता आणि GSTR-1A तिथे भरता.

तुमचा GSTIN save केलेला असावा — Settings → Business details & GST मध्ये. CGST + SGST की IGST ते त्यावरून ठरते आणि JSON साठीही तो लागतो.

GSTR-1A उघडा आणि महिना load करा

डाव्या menu मध्ये GST → More GST → GSTR-1A amendments A उघडा (मराठी menu मध्ये: GST → आणखी GST → GSTR-1A दुरुस्ती). इनव्हॉइसचा Return period B निवडा — उदाहरणात सप्टेंबर 2026, ज्याचे GSTR-1 आधीच भरले आहे — आणि Load registers C वर click करा.

इनव्हॉइस निवडा

Invoice to correct A मध्ये महिन्याच्या यादीतून इनव्हॉइस निवडा. कळवले होते तसे तपशील Original invoice B खाली दिसतात: ग्राहकाचा GSTIN, place of supply, taxable value आणि GST दर.

Type इनव्हॉइसवरून आपोआप ठरतो — Invoice to a registered buyer (B2BA), Large invoice to an unregistered buyer in another State (B2CLA), Credit / debit note (CDNRA) किंवा Export invoice (EXP-A). चुकीचा असेल तरच बदला.

दुरुस्ती टाका

Reason C निवडा — Wrong taxable value, Wrong buyer GSTIN, Wrong place of supply, Wrong GST rate किंवा Other — आणि जे चुकले ते field बदला:

Fieldकाय टाकायचे
Corrected invoice numberइनव्हॉइसवरून भरलेला असतो; नंबरच चुकला असेल तरच बदला.
Corrected buyer GSTINयोग्य GSTIN. नोंदणी नसलेल्या ग्राहकासाठी रिकामे ठेवा.
Corrected place of supplyयोग्य राज्य. त्यावरून ERP CGST + SGST (तुमचेच राज्य) की IGST (दुसरे राज्य) ते ठरवतो.
Corrected GST rateयोग्य दर.
Corrected taxable value (₹) Dयोग्य taxable value — उदाहरणात ₹37,100 ऐवजी ₹36,800.
Corrected cess (₹)cess लागू असेल तर.

दुरुस्ती save करा

Save correction (वरचा बॉक्स E) वर click करा. दुरुस्ती Corrections recorded for Sep 2026 A खाली दिसते: प्रकार आणि मूळ इनव्हॉइस, दुरुस्त तपशील आणि कारण, नवीन taxable value आणि जुनी (Was), दुरुस्त टॅक्स आणि स्थिती Recorded.

GSTR-1A JSON डाउनलोड करा

Download GSTR-1A JSON B वर click करा. फाइलमध्ये (नाव GSTR1A_<GSTIN>_2026-09.json सारखे) महिन्याच्या सर्व दुरुस्त्या असतात. ती स्वतः GST पोर्टलवर upload करा आणि GSTR-1A तिथे भरा. Export Excel C त्याच दुरुस्त्या तुमच्या नोंदीसाठी किंवा CA साठी worksheet म्हणून देते.

⚠️

GSTR-1A ने काय कळवले ते बदलते, तुमचा हिशोब नाही. इनव्हॉइसच हिशोबात बदलायचे असेल तर तुमच्या accountant च्या सल्ल्याने क्रेडिट किंवा डेबिट नोट वापरा.

नेहमीचे प्रश्न

दुरुस्ती save केल्याने माझे इनव्हॉइस किंवा हिशोब बदलतो का?
नाही. दुरुस्ती ही वेगळी नोंद आहे आणि ती GSTR-1A JSON मध्ये जाते. इनव्हॉइस, ग्राहकाची बाकी आणि तुमचे लेजर जसे आहेत तसेच राहतात.
Techstar ERP GSTR-1A भरतो का?
नाही. तो JSON तयार करतो. ती upload करणे आणि GSTR-1A भरणे तुम्ही स्वतः GST पोर्टलवर करता.
माझे इनव्हॉइस यादीत का दिसत नाही?
यादीत load केलेल्या महिन्याचीच इनव्हॉइस दिसतात. Return period मध्ये इनव्हॉइसचा महिना निवडा आणि पुन्हा Load registers वर click करा.
दुरुस्त टॅक्स कसा मोजला जातो?
दुरुस्त taxable value आणि दरावरून. दुरुस्त place of supply तुमचेच राज्य असेल तर टॅक्स CGST आणि SGST मध्ये विभागला जातो; नाहीतर IGST.
