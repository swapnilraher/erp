ई-वे बिल कब ज़रूरी है?

माल की कीमत सीमा से ज़्यादा हो तो माल चलने से पहले ई-वे बिल ज़रूरी है — एक राज्य से दूसरे राज्य में माल जाने पर यह सीमा ₹50,000 है। राज्य के अंदर सीमा राज्य के हिसाब से अलग होती है (जैसे महाराष्ट्र में ₹1,00,000)।

यह याद रखने की ज़रूरत नहीं: e-Way Bills सूची में ई-वे बिल ज़रूरी हो तो इनवॉइस पर Pending दिखता है, वरना उस बिक्री के राज्यों के हिसाब से लागू सीमा के साथ Not required (up to ₹…) दिखता है।

एक बार का सेटअप: ई-वे बिल पोर्टल लॉगिन

  1. ewaybillgst.gov.in पर अपने GSTIN के लिए API user बनाएँ (Registration → For GSP, अपना GSP चुनकर)।
  2. Techstar ERP में GST → E-Invoice / E-Way Bill → GST Configuration A खोलें (हिंदी menu में: GST → ई-इनवॉइस / ई-वे बिल)।
  3. बाईं ओर अपना GSTIN चुनें, e-Way Bill API user का नाम और पासवर्ड B डालें और save करें। Save करते समय लॉगिन पोर्टल पर जाँचा जाता है, और पासवर्ड encrypt करके रखे जाते हैं।
ℹ️

अभी API user नहीं है? फिर भी ERP इस्तेमाल कर सकते हैं: वही फ़ॉर्म भरें और Download JSON पर click करें। वह फ़ाइल ई-वे बिल पोर्टल पर upload करें, बिल वहाँ बन जाता है। (इस software से GST रिटर्न नहीं भरे जाते।)

e-Way Bills टैब खोलें

GST → E-Invoice / E-Way Bill पर जाएँ और e-Way Bills टैब A खोलें। हर सेल्स इनवॉइस उसके ग्राहक, तारीख, कीमत और ई-वे बिल की स्थिति के साथ दिखता है। इनवॉइस खोजने के लिए All / Active / Pending / Cancelled टैब या खोज बॉक्स इस्तेमाल करें।

इनवॉइस चुनें

इनवॉइस की लाइन पर Generate B पर click करें, या + New e-Way Bill C पर click करके सूची से इनवॉइस चुनें। सही इनवॉइस चुना है, यह जाँचने के लिए इनवॉइस का ग्राहक, GSTIN और कीमत दिखती है।

ढुलाई की जानकारी (Part B) भरें

Fieldक्या डालें
Mode of transportRoad (सड़क), Rail, Air या Ship।
Distance (km)अनुमानित दूरी। PIN कोड से पोर्टल को दूरी गिनने देनी हो तो खाली छोड़ें (NIC की PIN-to-PIN दूरी की लिंक दी गई है)।
Vehicle numberसड़क से: गाड़ी नंबर, जैसे MH12KT4521 — या उसकी जगह transporter ID दें।
Vehicle typeRegular, या Over dimensional cargo।
Transporter IDTransporter का GSTIN या TRANSIN। गाड़ी नंबर अभी पता न हो तो ज़रूरी।
Transporter name, LR no.वैकल्पिक। रेल, हवाई या जहाज़ से भेजने पर ढुलाई दस्तावेज़ का नंबर और तारीख ज़रूरी।
Delivery addressइनवॉइस के ship-to पते से भरता है। शहर और PIN कोड ज़रूरी।

Generate करें

डिलीवरी का City / place A और PIN code B जाँचें, फिर Generate e-Way Bill C पर click करें। ERP इनवॉइस और ढुलाई की जानकारी ई-वे बिल पोर्टल को भेजता है और ई-वे बिल नंबर व उसकी वैधता इनवॉइस पर दर्ज करता है। Download JSON D इसके बजाय पोर्टल पर upload करने की फ़ाइल बनाता है।

ई-वे बिल Active हुआ

इनवॉइस पर अब Active, 12 अंकों का ई-वे बिल नंबर और Valid up to (कब तक वैध) दिखता है। वैधता पोर्टल दूरी से तय करता है — सामान्य माल के लिए हर 200 km पर लगभग एक दिन।

प्रिंट, गाड़ी बदलना, समय बढ़ाना या कैंसिल करना

लाइन पर ⋯ बटन पर click करें:

  • Print e-Way Bill — प्रिंट ड्राइवर को दें; View on portal पोर्टल का रिकॉर्ड दिखाता है।
  • Update vehicle (Part B) — माल दूसरी गाड़ी में गया (गाड़ी खराब हुई, माल दूसरी गाड़ी में लादा); कारण चुनें।
  • Change transporter — बिल दूसरे transporter को दें।
  • Extend validity — बिल खत्म होने से 8 घंटे पहले से 8 घंटे बाद तक दिखता है, जब माल समय पर नहीं पहुँच सकता।
  • Cancel e-Way Bill — बनने के 24 घंटे के अंदर और रास्ते में माल की जाँच होने से पहले ही। कैंसिल हुआ बिल दोबारा इस्तेमाल नहीं होता; नया बनाएँ।

ई-वे बिल बनाने के और तरीके

  • इनवॉइस save करते ही — माल सीमा से ज़्यादा हो तो save हुए इनवॉइस पर Generate E-Way Bill लिंक के साथ पीली सूचना दिखती है। आप ई-इनवॉइस इस्तेमाल करते हों तो खुलने वाली विंडो में IRN बनाएँ; वही विंडो फिर ढुलाई की जानकारी पूछकर ई-वे बिल बनाती है। देखें सेल्स इनवॉइस कैसे बनाएँ।
  • From challan / return — डिलीवरी चालान, sales return और purchase return के लिए: दस्तावेज़ का नंबर डालें, जानकारी लाएँ और generate करें।
  • Trip sheet (combine bills) — ऊपर के ⋯ menu में: एक गाड़ी के कई बिलों के लिए एक consolidated ई-वे बिल।
  • Bills where I am the transporter — दूसरों ने आपके GSTIN को (transporter के रूप में) दिए ई-वे बिल।

आम सवाल

सूची में “Not required” दिखता है। फिर भी ई-वे बिल बना सकते हैं?
हाँ। हर इनवॉइस पर Generate बटन रहता है, जैसे सीमा से कम होने पर भी transporter ई-वे बिल माँगे।
लॉगिन या credentials की error आती है।
GST → E-Invoice / E-Way Bill → GST Configuration में e-Way Bill API user save करें (ऊपर एक बार का सेटअप देखें)। नाम और पासवर्ड ई-वे बिल पोर्टल पर जैसे बनाए, बिल्कुल वैसे ही हों।
गाड़ी नंबर ज़रूरी है?
सड़क से भेजने पर गाड़ी नंबर या transporter ID में से एक चाहिए। गाड़ी अभी तय न हो तो अभी transporter ID दें और बाद में Update vehicle (Part B) से गाड़ी जोड़ें।
ई-वे बिल में गलती हो गई।
24 घंटे के अंदर उसे कैंसिल करें (⋯ → Cancel e-Way Bill, कारण के साथ) और नया बनाएँ। सिर्फ़ गाड़ी बदली हो तो कैंसिल करने के बजाय Update vehicle इस्तेमाल करें।
क्या ई-वे बिल से मेरा हिसाब बदलता है?
नहीं। ई-वे बिल नंबर और वैधता रिकॉर्ड और प्रिंट के लिए इनवॉइस पर रखी जाती है; इनवॉइस की रकम और आपका हिसाब जैसा है वैसा ही रहता है।
